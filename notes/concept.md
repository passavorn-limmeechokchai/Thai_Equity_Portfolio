## 1. ผลตอบแทนและราคา (Asset Returns & Price Adjustments)

### 1.1 Simple Return vs Log Return
- **Simple Return ($R_t$):**
  $$R_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1$$
  - **การใช้งาน:** ใช้คำนวณ **ผลตอบแทนของพอร์ต (Cross-Sectional Portfolio Aggregation)**
  - **สูตรพอร์ต:** $R_{\text{port}, t} = \sum_{i=1}^N w_i R_{i, t} = \mathbf{w}^T \mathbf{R}_t$
  - **เหตุผล:** พอร์ตการลงทุนคือผลรวมเชิงเส้น (Linear Combination) ตามสัดส่วนเงินจริง จึงต้องใช้ Simple Return

- **Log Return / Continuously Compounded Return ($r_t$):**
  $$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1})$$
  - **การใช้งาน:** ใช้สำหรับการวิเคราะห์ **อนุกรมเวลา (Time-Series / Econometrics / Machine Learning)**
  - **คุณสมบัติบวกทบต้นข้ามเวลา (Time-Additivity):** $r_{0 \to T} = \sum_{t=1}^T r_t$
  - **ข้อควรระวัง:** ห้ามนำ Log Return ไปคูณน้ำหนักแล้วบวกกันข้ามหุ้น เพราะ $\ln(\sum w_i X_i) \neq \sum w_i \ln(X_i)$

> 💡 **ตัวอย่างให้เห็นภาพจริง (กับดักของ Simple Return ข้ามวัน):**
> สมมติมีเงิน 100 บาท:
> - วันที่ 1: หุ้นขึ้น +20% $\to$ เงินกลายเป็น 120 บาท
> - วันที่ 2: หุ้นตก -20% ($120 \times 0.20 = 24$ บาท) $\to$ เงินเหลือ **96 บาท**
> - ถ้าจับเปอร์เซ็นต์บวกกันดื้อๆ: $+20\% - 20\% = 0\%$ (ดูเหมือนเท่าทุน) แต่ความจริง **ขาดทุนจริง 4 บาท!** 
> - นี่คือเหตุผลว่าทำไม Simple Return บวกกันข้ามวันตรงๆ ไม่ได้ ต้องใช้ Log Return ในการวิเคราะห์ข้ามเวลา

### 1.2 Adjusted Close Price
- ปรับผลกระทบจาก Corporate Actions (เงินปันผล Dividend และการแตกพาร์ Stock Split) ย้อนหลังทั้งหมด
- สะท้อน **Total Economic Return** ของผู้ถือหุ้นจริง

> 💡 **ตัวอย่างให้เห็นภาพจริง (เงินปันผลที่หายไป):**
> ซื้อหุ้น PTT ราคา 100 บาท ต่อมาบริษัทจ่ายเงินปันผลสดเข้าบัญชีเรา 10 บาท
> - วันรุ่งขึ้น (วันขึ้นเครื่องหมาย XD) ราคาในกระดานจะปรับลงมาเหลือ 90 บาทโดยอัตโนมัติ
> - **ถ้าใช้ราคา Close ปกติ:** คอมพิวเตอร์เห็น 100 $\to$ 90 จะคิดว่าเรา **ขาดทุน -10%** (ทั้งที่เราได้เงินสด 10 บาท)
> - **ถ้าใช้ Adjusted Close:** ระบบจะย้อนไปปรับราคาฐานในอดีต ทำให้คอมพิวเตอร์รับรู้ว่าความมั่งคั่งเราเท่าเดิม (Total Return = 0%) ไม่ถูกหลอกว่าขาดทุน

## 2. ความผันผวนและเมทริกซ์ความเสี่ยง (Volatility & Covariance)

### 2.1 Square Root of Time Rule (Annualization)
- จำนวนวันทำการของตลาดหุ้นไทย: **$T \approx 252$ วันต่อปี**
- **Annualized Return:**
  $$\bar{R}_{\text{annual}} = 252 \times \bar{R}_{\text{daily}}$$
- **Annualized Volatility ($\sigma_{\text{annual}}$):**
  $$\sigma_{\text{annual}} = \sqrt{252} \times \sigma_{\text{daily}} \approx 15.87 \times \sigma_{\text{daily}}$$
  - **ที่มาทางสถิติ:** Variance มีคุณสมบัติบวกกันได้ตามเวลา $\text{Var}_{\text{annual}} = 252 \times \text{Var}_{\text{daily}}$ เมื่อแปลงเป็น Standard Deviation ($\sigma = \sqrt{\text{Var}}$) จึงต้องคูณด้วย $\sqrt{252}$

> 💡 **ตัวอย่างให้เห็นภาพจริง:**
> ถ้าหุ้นตัวหนึ่งผันผวนเฉลี่ยวันละ 1% ($\sigma_{\text{daily}} = 1\%$):
> - ถ้าเผลอคูณ 252 ตรงๆ: ความผันผวนทั้งปีจะกลายเป็น $252\%$ (ซึ่งไม่มีทางที่หุ้นปกติจะแกว่งกว้างขนาดนั้น)
> - แต่ถ้าคูณด้วย $\sqrt{252} \approx 15.87$: ความผันผวนทั้งปีจะอยู่ที่ $\approx 15.87\%$ ซึ่งตรงกับพฤติกรรมจริงในตลาด

---

### 2.2 Portfolio Variance ในรูปเมทริกซ์ (Matrix Notation)
สำหรับพอร์ตที่มีหุ้น $N$ ตัว และเวกเตอร์น้ำหนัก $\mathbf{w} = [w_1, w_2, \dots, w_N]^T$:
$$\sigma_{\text{port}}^2 = \mathbf{w}^T \mathbf{\Sigma} \mathbf{w} = \sum_{i=1}^N \sum_{j=1}^N w_i w_j \sigma_{ij}$$
$$\sigma_{\text{port}} = \sqrt{\mathbf{w}^T \mathbf{\Sigma} \mathbf{w}}$$
โดยที่ $\mathbf{\Sigma}$ คือ Covariance Matrix ขนาด $N \times N$ และ $\sigma_{ij} = \rho_{ij} \sigma_i \sigma_j$

> 💡 **ตัวอย่างให้เห็นภาพจริง (ทำไมต้องกระจายความเสี่ยง):**
> - ถ้าถือ **หุ้นสายการบิน 100%**: วันที่ราคาน้ำมันโลกพุ่ง ต้นทุนสูง หุ้นร่วง พอร์ตพัง
> - ถ้าถือ **หุ้นสายการบิน 50% + หุ้นโรงกลั่น 50%**: สองกลุ่มนี้มี Correlation ไม่สูงหรือวิ่งสวนทางกัน วันที่น้ำมันพุ่ง โรงกลั่นกำไรเยอะจะช่วยพยุงผลขาดทุนของสายการบิน ทำให้ภาพรวมพอร์ตมีความผันผวนต่ำลง

## 3. ตัวชี้วัดผลการดำเนินงาน (Performance & Risk Metrics)

### 3.1 Sharpe Ratio
$$\text{Sharpe Ratio} = \frac{R_p - R_f}{\sigma_p}$$
- $R_p$: Annualized Portfolio Return
- $\sigma_p$: Annualized Portfolio Volatility
- $R_f$: **Risk-Free Rate ของไทย** อ้างอิงจากตั๋วเงินคลัง/พันธบัตรรัฐบาลไทย 1 ปี หรืออัตราดอกเบี้ยนโยบายของ ธปท. (~2.25% - 2.50%)

> 💡 **ตัวอย่างให้เห็นภาพจริง (กองทุนไหนเก่งกว่ากัน?):**
> - **กองทุน ก:** ผลตอบแทน 15% ต่อปี แต่ความผันผวนสูงลิ่ว 30% $\to \text{Sharpe} = (15\% - 2.5\%) / 30\% = 0.41$
> - **กองทุน ข:** ผลตอบแทน 10% ต่อปี แต่นิ่งมาก ความผันผวนแค่ 5% $\to \text{Sharpe} = (10\% - 2.5\%) / 5\% = 1.50$
> - แม้ กองทุน ก จะได้กำไรเป็นเปอร์เซ็นต์มากกว่า แต่ **กองทุน ข มีประสิทธิภาพเหนือกว่ามาก** เพราะสร้างผลตอบแทนได้คุ้มค่าต่อความเสี่ยง 1 หน่วยมากกว่าเกือบ 4 เท่า

---

### 3.2 Wealth Index & Maximum Drawdown (MDD)
- **เส้นมูลค่าพอร์ตสะสม (Wealth Index $W_t$):** $W_t = W_0 \times \prod_{s=1}^t (1 + R_{\text{port}, s})$
- **จุดสูงสุดสะสมในอดีต (Running Peak):** $\text{Peak}_t = \max_{s \le t} (W_s)$
- **Drawdown ณ วันที่ $t$:** $\text{Drawdown}_t = \frac{W_t - \text{Peak}_t}{\text{Peak}_t} \le 0$
- **Maximum Drawdown (MDD):** $\text{MDD} = \min_{t} (\text{Drawdown}_t)$

> 💡 **ตัวอย่างให้เห็นภาพจริง (ดัชนีวัดความเจ็บปวด):**
> - ลงทุนเงิน 1,000,000 บาท พอร์ตโตไปแตะจุดสูงสุดที่ 1,500,000 บาท
> - ต่อมาเกิดวิกฤต COVID หุ้นตกหนัก พอร์ตดิ่งลงไปลึกสุดเหลือ 900,000 บาท ก่อนจะฟื้นตัว
> - $\text{Drawdown} = (900,000 - 1,500,000) / 1,500,000 = -40\%$
> - **ทำไมธนาคารถึงกลัว MDD:** เพราะต่อให้โมเดลระยะยาวจะดีแค่ไหน ถ้า MDD ลึกเกินไป (เช่น -40% ถึง -50%) ลูกค้าจะทนไม่ไหว ตื่นตระหนก (Panic) แล้วสั่งถอนเงินตัดขาดทุนที่ก้นเหวทันที

## 4. ความเสี่ยงหางซ้าย (Left-Tail Risk: VaR & CVaR)

กำหนดระดับความเชื่อมั่น $1-\alpha = 95\%$ ($\alpha = 0.05$):

### 4.1 Historical Value at Risk ($\text{VaR}_{95\%}$)
$$\text{VaR}_{\alpha} = - \text{Quantile}(R, \alpha)$$
- บอกว่าใน 1 วัน ด้วยความเชื่อมั่น 95% จะขาดทุนไม่เกินค่านี้ (หรือในวันที่แย่ที่สุด 5% จะขาดทุนอย่างน้อยเท่านี้)

### 4.2 Historical Conditional Value at Risk ($\text{CVaR}_{95\%}$)
$$\text{CVaR}_{\alpha} = - \mathbb{E}\left[ R \mid R \le -\text{VaR}_{\alpha} \right] = - \frac{1}{K} \sum_{t: R_t \le -\text{VaR}_\alpha} R_t$$
- บอกค่าเฉลี่ยของการขาดทุนทั้งหมดในวันที่หลุดเกณฑ์ 5% ไปแล้ว

> 💡 **ตัวอย่างให้เห็นภาพจริง (ทำไมดูแค่ VaR ถึงอันตรายถึงชีวิต):**
> เปรียบเทียบ 2 พอร์ตโฟลิโอ:
> - **พอร์ตที่ 1:** 95% ของวันปกติ ขาดทุนไม่เกิน -2% / และใน 5% วันที่แย่ที่สุด ขาดทุนเฉลี่ย **-3%**
> - **พอร์ตที่ 2:** 95% ของวันปกติ ขาดทุนไม่เกิน -2% / แต่ใน 5% วันที่แย่ที่สุด ขาดทุนเฉลี่ยดิ่งเหวถึง **-25%!**
> - **ถ้าดูแค่ VaR 95%:** ทั้งสองพอร์ตมี $\text{VaR} = -2\%$ เท่ากันเป๊ะ! (ผู้จัดการจะเข้าใจผิดว่าสองพอร์ตนี้ปลอดภัยเท่ากัน)
> - **แต่ CVaR จะเปิดโปงความจริง:** พอร์ต 1 มี $\text{CVaR} = -3\%$ ขณะที่ พอร์ต 2 มี $\text{CVaR} = -25\%$ ทำให้ทีมบริหารความเสี่ยงสั่งระงับพอร์ตที่ 2 ได้ทันท่วงที

## 5. กลยุทธ์จัดพอร์ต & กับดัก Error Maximizer

### 5.1 กลยุทธ์ทั้ง 4 แบบ
1. **Equal-Weight (EW):** $w_i = \frac{1}{N}$ (เกณฑ์มาตรฐาน Baseline)
2. **Inverse-Volatility (IV):** $w_i = \frac{1/\sigma_i}{\sum 1/\sigma_j}$ (หุ้นนิ่งได้น้ำหนักมาก หุ้นแกว่งได้น้ำหนักน้อย)
3. **Minimum-Variance (Min-Var):** $\min_{\mathbf{w}} \mathbf{w}^T \mathbf{\Sigma} \mathbf{w}$ ภายใต้ $\sum w_i = 1, 0 \le w_i \le 0.20$
4. **Maximum-Sharpe (Max-Sharpe):** $\max_{\mathbf{w}} \frac{\mathbf{w}^T \boldsymbol{\mu} - R_f}{\sqrt{\mathbf{w}^T \mathbf{\Sigma} \mathbf{w}}}$ ภายใต้ $\sum w_i = 1, 0 \le w_i \le 0.20$

### 5.2 ทำไม Max-Sharpe ถึงได้ฉายา "Error Maximizer"
- การคำนวณ Max-Sharpe ต้องป้อนค่าผลตอบแทนในอดีต ($\boldsymbol{\mu}$) ให้โมเดล
- **กับดัก:** "ผลตอบแทนในอดีตไม่ได้การันตีอนาคต" และเต็มไปด้วย Noise
- ถ้าหุ้นตัวหนึ่งบังเอิญราคาพุ่ง 300% ในอดีตเพราะกระแสเก็งกำไรชั่วคราว อัลกอริทึมจะเข้าใจผิดว่าหุ้นตัวนี้จะให้ผลตอบแทนมหาศาลตลอดไป จึงเทน้ำหนักเงินลงทุน 50-60% ไปที่หุ้นตัวนั้น
- เมื่อนำไปใช้งานจริง (Out-of-sample) หุ้นตัวนั้นหมดรอบและร่วงหนัก พอร์ตจึงมักจะขาดทุนยับเยิน
- **ทำไม Minimum-Variance ถึงมักชนะในโลกจริง:** เพราะมันไม่สนใจค่า $\boldsymbol{\mu}$ เลย สนใจแค่วิธีลดความผันผวนด้วย Covariance Matrix ($\mathbf{\Sigma}$) ซึ่งในทางสถิติ $\mathbf{\Sigma}$ คาดการณ์ได้แม่นยำและเสถียรกว่าผลตอบแทนมาก

## 6. ข้อควรระวังในการทดสอบย้อนหลัง (Backtesting Biases & Data Caveats)

### 6.1 Survivorship Bias (ความลำเอียงของผู้รอดชีวิต)
- **คืออะไร:** การหยิบหุ้นจาก SET50 ของ "วันนี้" แล้วเอาย้อนกลับไปทดสอบ 10 ปีก่อน (2015–2024)
- **ปัญหา:** หุ้นใน SET50 วันนี้คือหุ้นที่ **"รอดชีวิตและประสบความสำเร็จแล้ว"** แต่ย้อนไปปี 2015 มีหุ้นอีกหลายตัวที่เจ๊ง ขาดทุนหนัก หรือราคาตก 90% จนโดนถอดออกจากตลาดไปแล้ว
- **ผลกระทบ:** ทำให้ผลตอบแทน Backtest ในอดีต **ดูดีเว่อร์เกินจริงเสมอ** เพราะเหมือนเราแอบใช้ญาณทิพย์เลือกเฉพาะผู้ชนะในอนาคตมาจัดพอร์ต
- **วิธีรับมือ:** หุ้นที่ delist ไปแล้วข้อมูลหายากและแพง ในโปรเจกต์นี้เราจึงต้องเขียนระบุเรื่องนี้เป็น **Known Limitation (ข้อจำกัดของโมเดล)** ใน README ให้กรรมการเห็นว่าเราเข้าใจจุดนี้เป็นอย่างดี

### 6.2 Adjusted Close vs Close ปกติ
- **ทำไมต้องใช้ Adjusted Close:** เพราะย้อนกลับไปปรับผลกระทบจากเงินปันผล (Dividend) และการแตกพาร์ (Stock Split) ให้เรียบร้อย สะท้อน Total Economic Return จริง
- **ถ้าใช้ Close ปกติ:** วันขึ้นเครื่องหมาย XD หรือวันแตกพาร์ ราคาในกระดานจะฮวบลงมาทันที คอมพิวเตอร์จะมองว่าพอร์ตขาดทุนยับเยิน ทั้งที่จริงเราได้เงินปันผลสดเข้ากระเป๋า
